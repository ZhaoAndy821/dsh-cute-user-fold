# 预览图 / Preview images

这两张图被根目录 `README.md` 直接引用，会显示在仓库主页。

| 文件名 | 内容 |
|---|---|
| `collapsed.png` | 折叠态（默认）：长用户消息收成 8 行 + 底部渐隐 + 「展开」按钮 |
| `expanded.png` | 展开态：点击后完整显示，按钮变为「收起」 |

## 换图时的要求

- **宽度 ≥ 1000px**（GitHub 正文栏约 830px，宽图缩放后更清晰）；
- **PNG**；
- 截图前把窗口收窄到会话宽度，让「折叠 → 展开」的差别一眼可见；
- 想加深浅主题两张也行，命名如 `collapsed-dark.png`，同步改 `README.md` 里的引用。

> 图片是**唯一**能让人三秒看懂「这插件到底做了什么」的东西，文字描述替代不了 ——
> 所以这两张不是可选项，换图时请保持它们在 `README.md` 顶部的可见位置。
