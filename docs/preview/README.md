# 预览图 / Preview images

把截图放这个目录，文件名按下表 —— 根目录 `README.md` 顶部预留了引用（目前是注释状态）。

| 文件名 | 内容 |
|---|---|
| `collapsed.png` | 折叠态（默认）：长用户消息收成 8 行 + 渐隐 + 「展开」按钮 |
| `expanded.png` | 展开态：点击后的完整显示 |

放好图片后，**取消 `README.md` 顶部那段 HTML 注释的注释符**，图片就会出现在仓库主页。

建议：

- 宽度 **1200–1600px** 左右（GitHub 正文栏宽度约 830px，2x 图更清晰）；
- 深浅主题各一张更好，命名 `collapsed-dark.png` / `collapsed-light.png`；
- 截图前把窗口收窄到会话宽度，让「折叠 → 展开」的差别一眼可见。

> 图片是**唯一**能让人三秒看懂"这插件到底做了什么"的东西，
> 文字描述再多也替代不了 —— 所以这一段不是可选项。
